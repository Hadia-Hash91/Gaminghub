LANE RUNNER - TEXTURES
======================

Drop your picture files into THIS folder (IMAGES\LaneRunner\) using these
exact names. The game uses them automatically. While a file is missing,
Lane Runner keeps working with simple colored shapes instead, so you can
add art one piece at a time.

  player.png          The runner character (any size - scaled to fit).
                      If this file is missing, the game uses the character
                      you selected on the Character Selection screen.

  coin.png            The coin you collect.

  obstacle_tall.png   The overhead bar you must SLIDE under.
                      (drawn 48 x 90 pixels)

  obstacle_low.png    The hurdle on the track you must JUMP over.
                      (drawn 56 x 46 pixels)

  background.png      Full 900x600 background art for the level.
                      If missing, a simple sky/ground is drawn for you.

PNG format is recommended. Files just need to exist here with these names;
no code changes are needed.
