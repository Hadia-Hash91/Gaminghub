Drop your tile images into the IMAGES/ folder using these EXACT filenames.
Any square image works (ideally 128x128 or similar - it gets auto-scaled to fit each cell).

  watermelontile.png -> I piece  (long straight piece)
  sunflower.png      -> O piece  (2x2 square piece)
  hibiscus.png       -> T piece
  stars.png          -> S piece
  headphones.png     -> Z piece
  cassette.png       -> J piece
  guitar.png         -> L piece

Optional (fonts):
  font.ttf (in assets/) -> used for menu text, score, "next piece" label,
                           and the Lane Runner game's text. Without it, a
                           system font (arial) is used instead.

You don't need all 7 right away. Any piece missing its image just falls back to a
solid colored block automatically, so the game is playable at every stage.
